# Radar de Ofertas

Site estático com a curadoria automática das melhores promoções do varejo brasileiro
(Mercado Livre, Amazon, Shopee, AliExpress e outros).

O `index.html` é **gerado automaticamente** pelo robô Promobot (`npm run site`) e
republicado algumas vezes por dia. Não edite o arquivo à mão — a próxima geração
sobrescreve.

- Hospedagem: Vercel (projeto estático, sem framework).
- Publicação: push nesta branch `main` → a Vercel redeploya sozinha.

## Transparência

Este site participa de programas de afiliados e pode receber comissão por compras
qualificadas feitas através dos links, sem custo extra para quem compra. O aviso
completo fica no rodapé de todas as páginas.
